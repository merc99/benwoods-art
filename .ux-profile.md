# UX profile: benwoods.art

A designer who builds. The site should feel like a well-made spec sheet for physical and digital objects: cream paper
and near-black ink, a pixel wordmark, uppercase grotesk headlines, and a monospace system layer that labels everything.
Read this before any UI work. Built from `handoff/check-in/skills/ux-profile-template/TEMPLATE.md`.

## Aesthetic reference
**Editorial spec sheet: print-shop catalogue structure (hairlines, dashed grid, mono labels) with a pixel-type
signature. Calm and exact, with a few loud, deliberate moments.**
- Density: generous outside, exact inside. Big type and open bands, but every band has structure (a rule, a label,
  a coordinate, an index number). No empty voids. 44px minimum targets. 4/8 spacing rhythm. Page gutter 16px at 375,
  24px tablet, 40px desktop; content up to 1440px.
- Structure: a 12-column grid. Hairline rules (1px, `--rule`) separate rows; dashed rules (`--rule-dash`) mark the grid
  and section edges, like the current menu. Rules are the main structure, not cards or shadows.
- Radii: 0 for images, rules and tiles (it's print); 2px for small controls; full for pills and the status dot.
  No soft "card" radii.
- Borders and elevation: hairlines first. Shadows only on things that float (menu panel, command palette, the ledger
  cursor preview), and only one soft shadow.
- Color: monochrome. Cream `#FDF0D5` canvas and near-black `#0F0F0E` ink, swapped between themes. One signal color
  (vermilion: `#C2370F` light, `#FF5A2E` dark) for the live dot, the active filter mark and the current page marker.
  Never on buttons as a fill, never as a gradient. Project images are the color.
- Typography:
  - Wordmark: **Munro** (pixel, the current site's face). The wordmark only, plus the scramble.
  - Headlines: **Space Grotesk** 600–700, uppercase, tight tracking (−0.02em to −0.035em at display sizes, line height
    0.9–0.95).
  - Body: **Inter** 400/500, 17px desktop / 16px phone, line height 1.55, measure 64ch max. Text is ink or ink-2,
    never washed-out grey.
  - System layer: **Roboto Mono** 500, uppercase, +0.03em tracking, 13px (never under 12px), in ink-2/ink-3 at 7:1 or
    better, for labels, tags, spec rows, the status strip, counters, coordinates. Tabular figures for every number.
- Motion: chrome is 160–200ms, `--ease-out` in, `--ease-in` out, transform and opacity only. See the motion budget below.
- Modes: light (cream) and dark (near-black), both first-class, toggle in the header and menu, follows the system on
  first visit. Intentional full-bleed dark sections (`data-surface="ink"`) stay dark in both themes.

## Motion budget
Three tiers from the motion-budget skill: calm (everyday), moment (rare), scoped loop (one place each).

| Effect | Tier | Allowed only on |
|---|---|---|
| Wordmark decode (Munro scramble to "ben woods") | moment | The header wordmark: on first load and on mouse hover. Never loops |
| Hero type reveal (lines rise in, mono line types on) | moment | Home hero, once per visit |
| Glyph field: flow-field waves + turning faceted solid; click ripples | scoped loop | About's hero band only; no pointer tracking; paused offscreen and on hidden tab; one still frame under reduced motion |
| D20 in the glyph field: drag/flick spin with inertia, tap or Space/Enter to roll, number in glyphs (nat 20: amber + two soft rings) | moment | About's hero band only; reduced motion: a roll jumps to the result, no inertia |
| Marquee ticker | scoped loop | Inside the open menu only; reverses with scroll direction where used on the page |
| Foil card (tilt + white sheen) | calm | Flagship featured tiles only (Check-in, 100K Club, MMO Nodes), mouse hover |
| Card hover (image scale 1.02, title rule draws) | calm | Every other work tile |
| Rolling digits | calm | The Nashville clock, counts in the status strip and stats |
| Ledger row invert (hover and focus, colors only, 150ms) | calm | Work page list view only |
| Page transition (cross-fade + 8px rise) | calm | Route changes |
| Menu open (panel slide, links rise in, dashed grid draws) | calm | The slide-out menu |
| Lab demos | their own | Inside each Lab demo frame, in the origin project's style |

Rules: one effect per surface; hover effects gated to `(hover: hover)`; every effect has a reduced-motion branch
(instant or opacity only); no idle motion on everyday surfaces; sound off everywhere except opt-in Lab demos.

## Playful layer (scoped exceptions, deliberate, not slop)
1. **The pixel wordmark and its scramble.** Munro appears only in the wordmark. The scramble is the site's signature.
2. **Project brand colors inside their own frames.** Case studies and Lab demos may use their project's colors, fonts
   and effects (Check-in mint, 100K gold, Mega Roll acid colors…) inside the project's own frame. Site chrome never does.
3. **Foil on flagships.** The foil sheen is reserved for the three featured builds, so it means "flagship".
4. **The glyph field.** One hero-level WebGL moment, on About. Nowhere else gets a shader.

## Banned
- Dark gradient overlays on images; titles go below images.
- Uniform tile grids on Home and Work (vary the row structure; keep one cover ratio within a row).
- "Design engineer" labels in visible copy (services are Product design · Front end · Brand & print).
- Washed-out grey body text (nothing under 4.5:1, ever).
- Gradient or multi-color buttons; glow borders; glassmorphism.
- Rounded "SaaS cards" with drop shadows as the default container.
- Decorative icons without a job; emoji as UI icons.
- A "View portfolio" button standing in for a hero.
- Project brand colors or fonts in site chrome.

## Accessibility
**WCAG 2.2 AA.** Body text ≥ 4.5:1, large text and UI borders ≥ 3:1, in both themes (checked: ink 16.3:1, ink-2
10.6:1, ink-3 8.4:1 on cream; 16.3 / 12.5 / 8.9:1 on near-black; signal 4.8:1 / 6.2:1). Visible focus: 2px solid ink
outline, 3px offset. 44×44 targets. Semantic headings (one h1 per page), real alt text, skip link, `prefers-reduced-motion`
and `prefers-color-scheme` respected. Menu and palette trap focus and return it.

## Voice
**Plain, specific, first person, a little dry.** Say what was built and what it does. Accurate about status: "portfolio
build", "concept", "placeholder data", "in progress" where the handoff says so. No hype words ("revolutionary",
"seamless", "elevate"). Sentence case in body; uppercase only in the headline face and mono labels. Verbs on buttons
("View live site", "Download resume").

## Icons
**Lucide** (`lucide-react`), 1.5px stroke, 16–18px, only where an icon does a job (external link arrow, theme toggle,
close, view toggles). Arrows in mono text use the glyph `↗` / `→`.
