# UX profile: benwoods.art

A designer who builds. The site should feel like a well-made spec sheet for physical and digital objects: cream paper
and near-black ink, a pixel wordmark, uppercase grotesk headlines, and a monospace system layer that labels everything.
Read this before any UI work. Built from `handoff/check-in/skills/ux-profile-template/TEMPLATE.md`; brought in line
with the live site on 2026-10-24 (the card frame, the interactive covers, the idle tile glow).

## Aesthetic reference
**Editorial spec sheet: print-shop catalogue structure (hairlines, dashed rules, mono labels) with a pixel-type
signature. Calm and exact, with a few loud, deliberate moments.**
- Density: generous outside, exact inside. Big type and open bands, but every band has structure (a rule, a label,
  an index number). No empty voids. 44px minimum targets. 4/8 spacing rhythm. Page gutter 16px at 375, 24px tablet,
  40px desktop; content up to 1440px.
- Structure: a 12-column grid. Hairline rules (1px, `--rule`) separate rows; dashed rules (`rule-dash-b`) mark section
  edges. No vertical column lines on page backgrounds; only the menu draws its dashed grid. Rules structure the page;
  the one container is the card frame below. On phones, section headers stack (index, then title, then meta and link).
- The card frame (`Bezel`, chosen 2026-10-23): every image that stands for a project or a piece of work sits in one
  dark bezel: `#161615` with a `#262624` 1px edge, 6–8px of padding (4–6px small), outer radius 16–22px (12px small),
  inner radius 10–14px (7px small), and a soft drop shadow that sits mostly below it (`--frame-shadow`; on hover the
  deeper `--frame-shadow-hover`). Used on work cards, featured builds, case-study covers and galleries, merch,
  previous/next thumbnails and palette swatches; the same frame in both themes. Playful galleries (Merc Eats) keep
  their loose, tilted prints instead. Rules, labels and text never get a frame.
- Radii: the card frame as above; 0 for rules; 2px for small controls; full for pills and the status dot.
- Borders and elevation: hairlines first. Shadows on the card frame and on things that float (menu panel, command
  palette, lightbox), one soft shadow each.
- Color: monochrome. Cream `#FDF0D5` canvas and near-black `#0F0F0E` ink, swapped between themes. One signal color
  (vermilion: `#C2370F` light, `#FF5A2E` dark) for the live dot, active marks, the current page marker and the pixel
  tiles' warm glow. Never on buttons as a fill, never as a gradient. Project images are the color.
- Typography:
  - Wordmark: **Munro** (pixel). The wordmark only, plus the scramble.
  - Headlines: **Space Grotesk** 600–700, uppercase, tight tracking (−0.02em to −0.035em at display sizes, line height
    0.9–0.95). With Inter 400 and Roboto Mono 500 that's four weights site-wide, on purpose: the display face needs both.
  - Body: **Inter** 400/500, 17px desktop / 16px phone, line height 1.55, measure 64ch max. Text is ink or ink-2,
    never washed-out grey. On phones, long story text folds after ~10 lines behind "Read more".
  - System layer: **Roboto Mono** 500, uppercase, +0.03em tracking, 13px (never under 12px), in ink-2/ink-3 at 7:1 or
    better, for labels, tags, spec rows, counters and the clock. Tabular figures for every number.
- Motion: chrome is 160–200ms, `--ease-out` in, `--ease-in` out, transform and opacity only. Card hovers are slower on
  purpose: the frame lifts 4px over 800ms on a soft ease while its deeper shadow fades in, so they read as weight,
  not as feedback. In-page links scroll smoothly; route changes don't. See the motion budget below.
- Modes: light (cream) and dark (near-black), both first-class, toggle in the header and menu, follows the system on
  first visit. Intentional full-bleed dark sections (`data-surface="ink"`) stay dark in both themes.
- Home opens on one full screen: the name and lede over the pixel tiles, the Selected work line at its foot, and the
  work below the fold.

## Motion budget
Three tiers: calm (everyday), moment (rare), scoped loop (one place each).

| Effect | Tier | Allowed only on |
|---|---|---|
| Wordmark decode (Munro scramble to "ben woods") | moment | The header wordmark: on first load and on mouse hover. Never loops |
| Hero type reveal (lines rise in, lede fades up) | moment | Home hero, once per visit |
| Selected work arrow nudge | calm | The Home hero's Selected work line only, after the reveal |
| Pixel tiles: idle wave, drifting signal-color warmth and the odd bloom; hover trail and click color pop (mouse) | scoped loop | Page heroes and the footer; built after first paint, paused offscreen and on hidden tabs; still under reduced motion |
| Glyph field: flow-field waves + a lit, faceted D20; click ripples | scoped loop | About's hero band only; paused offscreen and on hidden tab; one still frame under reduced motion |
| D20 roll: drag/flick spin with inertia, tap or Space/Enter to roll, number on the front face (nat 20: amber + two rings) | moment | About's hero band only; reduced motion: a roll jumps to the result |
| Marquee ticker | scoped loop | Inside the open menu only |
| Card frame hover (4px lift, deeper shadow, title rule draws) | calm | Every work card, featured build, merch tile and previous/next thumbnail; mouse hover |
| Rolling digits | calm | The Nashville clock |
| Page transition (cross-fade + 8px rise) | calm | Route changes, not the first load |
| Menu open (panel slide, links rise in, dashed grid draws) | calm | The slide-out menu |
| Merc peek (rises from the footer, "Meet Merc" bubble) | moment | The footer's bottom-right corner, once per arrival |
| Interactive case-study covers (100K crest on silk, Mega Roll layers, Rat Mats rat and cheese, Retro-futurism line glow, live Check-in and MMO frames) | their own | Inside that project's cover frame, in the project's style; each has a reduced-motion branch |
| Lab demos | their own | Inside each Lab demo frame (and a case study's Interactive section), in the origin project's style |

Rules: one effect per surface; hover effects gated to `(hover: hover)`; every effect has a reduced-motion branch
(instant or opacity only); no idle motion on everyday surfaces beyond the pixel tiles; sound off everywhere except
opt-in Lab demos.

## Playful layer (scoped exceptions, deliberate, not slop)
1. **The pixel wordmark and its scramble.** Munro appears only in the wordmark. The scramble is the site's signature.
2. **Project brand colors inside their own frames.** Case studies and Lab demos may use their project's colors, fonts,
   shaders and effects (Check-in mint, 100K gold and silk, Mega Roll acid colors…) inside the project's own frame.
   Site chrome never does.
3. **The glyph field.** The site's own hero-level moment, on About. Shaders elsewhere live only inside a project's frame.
4. **Merc.** The cat who peeks up from every footer and links to his page.

## Banned
- Dark gradient overlays on images; titles go below images.
- Uniform tile grids on Home and Work (vary the row structure; keep one cover ratio within a row).
- "Design engineer" labels in visible copy (services are Product design · Front end · Brand & print).
- Washed-out grey body text (nothing under 4.5:1, ever).
- Gradient or multi-color buttons; glow borders on chrome; glassmorphism.
- Light "SaaS cards" (white boxes with soft radii and shadows) as containers. The dark card frame is the one container,
  and only for images.
- Decorative icons without a job; emoji as UI icons.
- A "View portfolio" button standing in for a hero.
- Project brand colors or fonts in site chrome.
- "No AI" claims on work that used AI anywhere (say exactly what was hand-made, e.g. "No AI in the artwork").

## Accessibility
**WCAG 2.2 AA.** Body text ≥ 4.5:1, large text and UI borders ≥ 3:1, in both themes (checked: ink 16.3:1, ink-2
10.6:1, ink-3 8.4:1 on cream; 16.3 / 12.5 / 8.9:1 on near-black; signal 4.8:1 / 6.2:1). Visible focus: 2px solid ink
outline, 3px offset. 44×44 targets (`hit-44` gives small text links an invisible 44px area). Semantic headings (one h1
per page), real alt text, skip link, `prefers-reduced-motion` and `prefers-color-scheme` respected. Menu, palette and
lightbox trap focus and return it. Card links are named by their visible text (title, year, tags), with the card image
decorative.

## Voice
**Plain, specific, first person, a little dry.** Say what was built and what it does. Accurate about status: "portfolio
build", "concept", "placeholder data", "in progress" where the handoff says so. No hype words ("revolutionary",
"seamless", "elevate"). Sentence case in body; uppercase only in the headline face and mono labels. Verbs on buttons
("View live site", "Download resume"). Hand-drawn work says so in its Medium row ("Drawn by hand, digitally. No AI.").

## Icons
**Lucide** (`lucide-react`), 1.5px stroke, 16–18px, only where an icon does a job (theme toggle, close, play, lightbox
arrows). Arrows in mono text use the glyph `↗` / `→` / `↓`.
